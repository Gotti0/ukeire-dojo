## 배경

T6는 AI 최선과 다른 타패를 고르면 사용자가 지정한 CLI로 해설을 생성한다. 검증된 부분을 생성 중에 표시하고 앱 타임아웃 없이 완료 또는 사용자 취소를 기다려야 한다.

## 문제

세 CLI의 텍스트 스트리밍 이벤트가 서로 다르다. 수치와 단위가 델타 경계에서 잘릴 수 있어 수치 검증에는 완결된 문장이 필요하다. Codex 데스크톱에 설정된 모델은 같은 PC의 CLI 로그인 계정에서 지원되지 않았다.

## 결정과 근거

- Codex는 App Server의 텍스트 델타를 받고 CLI 로그인 계정의 모델 목록에서 기본 모델을 고른다. agy와 Claude Code는 비대화형 JSON 스트림의 해설 텍스트만 받는다.
- 모델은 수치와 패를 참조 키로 출력한다. 서버가 완결된 줄의 참조를 확인해 실제 샨텐, 유효패 수, 표시 정밀도에 맞춘 AI 손실로 치환한다. 직접 쓴 숫자나 알 수 없는 참조가 포함된 줄은 공개하지 않는다.
- 클라이언트 연결이 닫히면 CLI 프로세스를 정리한다. 출력이 없는 동안에도 연결을 확인하는 이벤트를 보내고, 서버의 해설 실행 수는 두 건으로 제한한다.

## 검증

- 실제 문제은행의 같은 문제로 Codex CLI는 12.64초, agy CLI는 32.16초에 완료했다. 둘 다 완료 전에 검증된 세 문장을 받았다.
- pytest 55개, Vite 프로덕션 빌드 통과. 세 CLI의 텍스트 이벤트 형식, 미등록 수치 참조 거부, 프로세스 종료를 테스트했다.
- Chromium에서 선택 UI를 사용해 첫 문장을 16.5초에 받은 뒤 완료 표시가 따로 나타나는 것을 확인했다. 다음 요청을 취소했을 때 브라우저와 서버 모두 연결 종료를 확인했다.

## 미해결

- Claude Code CLI의 로그인 세션이 만료돼 인증 오류 처리까지 실측했다. 로그인 갱신 후 실제 해설 스트리밍과 완료 시간을 확인해야 한다.
- 측정한 agy CLI 실행은 15초 목표를 넘겼다.
