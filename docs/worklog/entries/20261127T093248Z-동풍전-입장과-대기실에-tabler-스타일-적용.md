## 배경

이전 Tabler 변경은 도움말과 대국 결과에 적용했다. 사용자가 동풍전 모드에서 첫 화면을 열었을 때 변화가 보이지 않았다.

## 문제

방 만들기와 초대 코드 입장이 같은 줄에 표시됐다. 입장 화면과 방 대기실에서도 도움말·결과와 같은 카드 스타일을 유지해야 했다.

## 결정과 근거

입장 화면은 공통 닉네임 필드 아래에서 방 만들기와 초대 입장을 카드 두 개로 안내한다. 방 대기실의 안내와 좌석에도 공통 카드 스타일을 쓴다. 변경 범위를 방에 들어가는 화면으로 제한해 대국 도중의 마작판과 입력 상태에 영향을 주지 않았다.

## 검증

- Node 테스트 4개와 Vite 프로덕션 빌드 통과.
- Chromium에서 1323px 두 열, 360px 한 열과 가로 넘침 없음, 방 생성, 초대 입장, 양쪽 준비와 대국 시작을 확인했다.

## 미해결

- 모바일 실기기에서 확인하지 않았다.
