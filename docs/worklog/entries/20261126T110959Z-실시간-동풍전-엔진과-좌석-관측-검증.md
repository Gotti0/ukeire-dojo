## 배경

두 동풍전에서 배패·패산을 공유하되 사람의 행동을 자유롭게 받는 2단계 멀티플레이를 설계했다.

## 문제

기존 연동은 완성된 패보를 분석한다. 새 기능은 게임 진행 중에 사람의 선택을 받고, 다른 AI 좌석은 합법 행동을 고르고, 필요할 때만 사람의 현재 타패 후보를 평가해야 한다. 반장 기본 진행은 동풍전 종료 규칙과 다르다.

## 결정과 근거

- Epsilon 엔진의 좌석별 합법 행동과 응답 일괄 확정을 재사용하고, 앱이 동풍전의 시작·종료와 국·본장별 패산을 관리하는 방식을 택했다. 한 경기의 연장이 다른 경기의 공통 국 패산에 영향을 주지 않게 하기 위해서다.
- 추천은 좌석별 관측에서 얻은 일반 타패 값으로 계산한다. 패산 및 상대 손패가 있는 전체 관측은 추천 입력에 쓰지 않는다.
- CUDA jar에 CPU DLL 리소스를 보태 모델 로딩은 복구했지만 첫 평가에서 NaN이 나왔다. 현재 진행 검증은 CUDA 결과를 사용한다.

## 검증

- 실제 체크포인트로 동풍전 두 경기 완료. 공통 국·본장 4개에서 물리 패산과 초기 배패가 일치했고 최종 점수는 달랐다. 여러 좌석 응답 창 6개를 처리했다.
- 1행 추론 p95는 AI 판단 15.71ms(318건), 타패 추천 15.99ms(128건)였다. 상대 비공개 패 변경에도 현재 좌석 모델 입력이 같았다.
- 동4국 친 텐파이 연장, 친 노텐 종료, 남은 공탁 수령을 별도 상태에서 확인했다.
- Java 컴파일과 CUDA 실험 종료 코드 0. 기존 Python 회귀 테스트 55개 통과.

## 미해결

- CPU 추론 NaN의 원인은 추가 확인이 필요하다. 단일 관측 외의 좌석별 API 응답 분리, 연장 경로 분기의 통합 검증, 브라우저 왕복과 여러 방 동시 처리량은 후속 범위다.
- 동풍전 종료 세부 정책을 정해야 한다. 동남전에서 학습한 모델의 손실을 동풍전 종료 정책에서 어떻게 해석할지도 별도로 확인한다.
