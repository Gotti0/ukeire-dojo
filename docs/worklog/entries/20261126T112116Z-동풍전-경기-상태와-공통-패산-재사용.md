## 배경

T7은 엔진에 외부 패산을 넣고 전체 합법 행동을 진행할 수 있음을 확인했다. 두 동풍전이 다른 경로로 진행된 경우에도 대응하는 국을 같은 조건으로 시작해야 한다.

## 문제

Epsilon의 반장 단위 연속 진행은 경기가 지나온 국의 개수에 따라 패산을 바꾼다. 또한 기록용 국 시작 API는 한 국을 처리한 뒤 다음 국을 자동으로 배패하지 않는다. 동4국 종료 때 남아 있는 공탁은 앱이 정산해야 한다.

## 결정과 근거

- 경기 쌍이 국·본장 키로 최초 셔플 결과를 보관한다. 서로 다른 연장 경로에서 공통 키에 다시 도달하면 이전 배열을 재사용한다.
- 경기에서는 각 결정 번호의 좌석별 응답을 검증한 뒤 엔진에 일괄 전달한다. 국말 및 다음 국 배패를 분리해 방에서 정산 상태를 표시할 수 있게 했다.
- 동4국에서 친이 넘어가면 종료하는 T7 규칙으로 연결했다. 일반 국 정산과 토비는 기존 Epsilon 결과를 사용하고, 앱이 추가로 끝낸 경기에서는 남은 공탁을 1위에 지급한다.

## 검증

- Epsilon 규칙 엔진으로 두 경기를 완료했다. 두 번째 경기만 동4국 2본장에서 연장했고 양쪽이 동4국 3본장에서 같은 배패와 도라 표시패를 받았다. 공통 국에서 추가 셔플이 발생하지 않았다.
- 동4국 친 텐파이 연장, 친 노텐 종료, 점수·공탁 이월, 종료 공탁 지급, 동점 순위, 0점과 음수 점수를 검증했다. 이전 결정 재전송과 불법 행동도 거부했다.
- Java 21 대상 컴파일과 통합 검증 3개, 기존 Python 테스트 55개 통과.

## 미해결

- 방과 참가자 연결, 좌석별 브라우저 응답은 T9에 남아 있다. 남입과 오라스 친 조기 종료는 후속 규칙 후보다.
