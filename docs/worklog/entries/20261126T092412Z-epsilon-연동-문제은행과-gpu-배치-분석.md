## 배경

패효율 트레이너에 AI 채점을 붙이려면, 판단마다 전체 후보의 가치를 주는 공개 모델과 그 모델로 만든 현실적인 국면이 필요했다. 2026-11 기준 로컬에서 쓸 수 있는 공개 가중치는 Epsilon-Prism v760(가중치 MIT, 코드 GPL-3.0)뿐이었다. Mortal은 가중치를 공개하지 않는다.

## 문제

- v760 릴리스는 Java/DJL 기반이고 Python API가 없다.
- 자기대국을 패보로 남기는 명령이 릴리스 jar에 없다.
- 리뷰어 백엔드는 저자 포크 DJL이 GitHub Packages에만 있어 Maven 빌드가 막힌다.
- 시스템 JDK 23이 오래된 VC++ 런타임(14.36)을 묶어 libtorch 2.11이 초기화되지 않는다.
- CPU 추론은 프로세스당 1코어만 써서, 자기대국 초당 50판단, 분석 초당 175판단(엔진 4개)에 그쳤다.

## 결정과 근거

- 분석은 리뷰어 stdio 호스트를 상주 자식 프로세스로 쓴다. 처음에는 Java 브리지를 직접 만들려 했다. 리뷰어에 같은 역할의 stdio 프로토콜이 이미 있어서 버렸다.
- 리뷰어는 v760 태그 소스를 릴리스 jar 위에서 javac로 컴파일한다(오류 0). main 소스는 패키지 구조가 바뀌어 릴리스 jar와 맞지 않는다.
- JDK 문제는 시스템 JDK를 고치지 않고 사본의 런타임 DLL 3개만 바꿔 푼다.
- 자기대국 기록기는 mjai로 직접 만든다. 엔진의 TenhouLogWriter는 tensoul JSON이라 리더가 읽지 못해 버렸다. hora의 deltas를 일부러 쓰지 않았는데, 나중에 main 리더는 deltas를 요구해서 이 mjai 패보는 v760 리뷰어로만 분석된다.
- 릴리스 v760으로는 NVIDIA GPU를 쓸 수 없다. Prism의 packed relation attention은 GPU 구현이 ROCm 빌드에만 있다. CUDA JNI 44MB를 받아 넣어 봐도 같은 오류가 났다. 대신 Epsilon main의 자체 CUDA 커널(Kernels.NATIVE)을 sm_89로 빌드했다. CMake는 CUDA의 VS 통합이 없어 Ninja 생성기를 쓴다. v760 가중치는 main에서 그대로 열린다.
- GPU 리뷰어는 한 반장의 판단을 1행씩 평가해서 엔진 8개로도 CPU의 1.5배에 그쳤다. 그래서 리뷰어의 Analysis와 ResultWriter를 재사용하는 배치 분석기를 만들었다. 반장마다 스레드를 두고, 평가 요청을 모아 NetworkPolicy.submit으로 보낸다. 배치는 시간 제한이 아니라 모든 작업 스레드가 기다리는 순간에 보낸다. 시간 제한은 배치를 키우지 못하고 지연만 늘린다.
- 정정 1: 보상을 처음에 "2, 1/3, 0, −1"로 적었다. 모델 zip README 기준으로 2/3, 1/3, 0, −1이다.
- 정정 2: 문제 키 (패보, 국 번호, 단계)는 연장국에서 겹친다. 키에 본장을 넣었다.
- 저장소 이름과 패키지 이름에서 LuckyJ(Tencent의 마작 AI)를 뺐다(ukeire-dojo, ukeire_dojo). 관계가 있는 것처럼 오해될 수 있어서다.

## 검증

- 샨텐 계산기를 Epsilon 샨텐 테이블과 무작위 손패 2만 개로 대조했다. 불일치는 0이었다.
- 자기대국 패보 18개(v760 mjai)와 GPU 천봉 XML 16개가 모두 리뷰어 재생 검증을 통과했다.
- 배치 분석기의 출력을 리뷰어 GPU 출력과 2,295판단에서 대조했다. 순서, 후보, 손실이 일치했고 최대 차이는 0이었다.
- GPU BF16과 CPU FP32는 927판단 중 손실 차이 0.01 이상이 1개였다. 문제은행 통계도 같았다(불일치 36.7%, 36.9%).
- 처리량(RTX 4070 Ti): 자기대국은 256반장 18초(9,226판단/s), 배치 분석은 256반장 21.6초(7,681판단/s).
- 패키지 이름을 바꾼 뒤 pytest 31개가 통과했다. 배치 분석 출력은 이름을 바꾸기 전과 같았다.

## 미해결

- 이제 병목은 Python의 문제 추출이다. 256반장에 303초가 걸린다.
- 더블 론, 도중 유국, 대명깡의 mjai 기록 경로는 실제 데이터로 검증하지 못했다.
- 트레이너 화면(T4), 오답 기록(T5), 해설(T6)은 아직 없다.
- GPU 빌드는 저자 포크 DJL 스냅숏(0.40.7)과 main 커밋 7630d15에 기댄다. 스냅숏이 지워지면 다시 빌드할 수 없다.
