## 배경

사람 1명과 AI 3명인 방에도 2~4인 방과 같은 두 경기 재대국 규칙이 적용됐다.

## 문제

첫 경기의 타패 추천을 방 서버와 Java 엔진이 각각 막고 있었다. 싱글플레이에 한해 첫 경기부터 추천을 허용하고 재대국을 막으려면 방 정책과 엔진의 후보 평가를 분리해야 했다.

## 결정과 근거

시작 시 사람 좌석 수로 싱글플레이 여부를 확정한다. 방 서버는 추천과 재대국의 허용 여부를 결정하고 Java 엔진은 전달받은 경기의 합법 타패를 평가한다. 싱글플레이는 기존 경기 정산을 표시하고 결과 화면에서 재대국 안내를 생략한다.

## 검증

- Java 대국 테스트 5개, Node 프롬프트 테스트 4개, Vite 빌드 통과.

- GPU 테스트를 제외한 Python 테스트 62개 통과. 싱글플레이의 첫 타패 추천, 한 경기 정산, 재대국 요청 거부를 HTTP 테스트에서 검증했다.

- Prism GPU와 Chromium에서 첫 타패 추천, 프롬프트 복사 버튼, 한 경기 완주 후 결과와 방 나가기를 확인했다. 기존 멀티플레이 시나리오 A~D도 통과했다.
