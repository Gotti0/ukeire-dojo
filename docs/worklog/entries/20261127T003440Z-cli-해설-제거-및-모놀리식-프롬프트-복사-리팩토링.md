## 배경

T6에서는 서버 호스트에 로그인된 Codex, agy, Claude Code CLI를 자식 프로세스로 실행해 타패 해설을 스트리밍했다. 외부 무료 호스팅이나 다른 환경으로 배포·공유할 때 로컬 CLI 인증과 실행 파일 의존성이 장애물이 되었고, 사용자가 원하는 외부 AI 웹 서비스에 직접 질문할 수 있는 단순한 흐름이 필요했다.

## 문제

서버가 로컬 CLI를 호출하면 호스팅 환경마다 CLI 설치와 로그인 유지가 필수이고, 동시 실행 제한 및 스트림·자식 프로세스 수명 관리 복잡도가 따라온다. 또한 기존 CLI 해설은 AI 최선과 불일치할 때만 열 수 있었고, 비HTTPS 외부 접속 환경(예: 평문 HTTP DDNS)에서는 `navigator.clipboard` API가 비활성화될 수 있다.

## 결정과 근거

- 서버의 CLI 해설 실행 경로와 스트리밍·수치 치환 로직을 모두 제거하고, 프론트엔드에서 국면과 채점 결과를 즉시 조합해 단일 완성형(모놀리식) 한국어 프롬프트를 생성하도록 바꿨다. 별도 서버 API 호출 없이 동작하므로 호스팅 환경 의존성이 사라진다.
- 프롬프트에는 해설 규칙(제공 수치 엄수, 순위 효용 손실 정의, 패 표기법), 장·국·도라·내 손패·상대별 점수·리치·울기·버림패 등 전체 테이블 맥락, 채점 요약, 전체 후보 타패 마크다운 표, 일치/불일치 여부에 따른 맞춤 질문을 모두 포함했다.
- 채점 결과 화면에서 AI 최선 일치 여부와 무관하게 항상 복사 UI를 표시해 정답 근거 확인도 가능하게 했다. 클립보드 복사는 Clipboard API 우선 시도 후 `execCommand("copy")` 폴백과 접이식 `<textarea>` 미리보기를 두어 비HTTPS 환경에서도 복사 실패 없이 대응한다.

## 검증

- Node 내장 테스트(`node --test`)로 불일치·일치·울기 직후 타패(`draw=null`)·적도라·리치 권장 등 프롬프트 생성 테스트 3건이 모두 통과했다.
- Vite 프로덕션 빌드(34개 모듈, 655ms)가 오류 없이 완료됐다.
- Python 테스트(`-m "not gpu"`)에서 기존 56건과 제거된 해설 엔드포인트 `404` 확인 테스트 1건까지 총 57건이 모두 통과했다(1건 GPU 테스트 제외).
- 저장소 검색으로 기존 CLI 해설 모듈·엔드포인트·선택 UI 잔여 참조가 제거됐음을 확인했다.

## 미해결

- 실제 외부 웹 AI(ChatGPT, Claude, Gemini)에 생성된 프롬프트를 붙여넣은 정성 품질 비교와 비HTTPS 브라우저에서의 수동 클립보드 폴백 동작은 실환경에서 추가 확인하지 않았다.
