## 배경

패효율 트레이너의 채점 결과에 해설 프롬프트 복사가 있었고, 2경기 타패 추천에서도 같은 복사 동작이 필요했다.

## 문제

타패 추천은 플레이어가 선택하기 전의 동풍전 국면이다. 트레이너의 채점 프롬프트는 이미 고른 타패와 유효패 계산 결과를 전제로 한다.

## 결정과 근거

국면 표기와 복사 UI는 공유한다. 추천용 프롬프트는 자기 손패와 공개 정보, 후보별 AI 손실을 받아 추천 근거를 묻는다. 기존 추천 표시 조건 안에 복사 UI를 두어 현재 추천이 화면에서 사라질 때 함께 내려가게 했다.

## 검증

- Node 프롬프트 테스트 4개, Vite 프로덕션 빌드, GPU 제외 방 테스트 9개 통과.

- 실제 Prism GPU와 Chromium으로 2경기 추천 요청자의 클립보드 내용과 상대 화면에서의 버튼 미표시를 확인했다. E2E 시나리오 A~D 통과.

## 미해결

- 외부 AI 서비스에 붙여넣은 뒤의 응답 품질은 평가하지 않았다.
