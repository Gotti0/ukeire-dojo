## 배경

패효율 채점과 동풍전의 시작·추천·재대국 흐름을 앱 안에서 안내할 필요가 생겼다.

## 문제

멀티플레이 화면이 마운트 해제되면 방 스트림이 닫힌다. 도움말을 읽는 시간 동안 연결이 끊기면 AI 대타가 시작될 수 있다.

## 결정과 근거

공유 가능한 /help 주소와 상단 도움말 버튼을 제공한다. 기존 화면을 숨긴 채 유지해 채점 결과와 방 스트림을 보존하고, 도움말이 열려 있을 때는 트레이너의 다음 문제 단축키를 끈다. 도움말로 직접 접속할 때는 모드를 선택한 뒤에 게임 화면을 연다.

## 검증

- Node 프롬프트 테스트 4개, Vite 빌드 및 diff 검사 통과.
- Chromium에서 /help 직접 접속, 360px·1280px 레이아웃, FAQ, 뒤로 가기, 채점 결과 유지, 실시간 대국 스트림과 추천 패널 유지를 확인했다.

## 미해결

- 모바일 실기기에서는 확인하지 않았다.
