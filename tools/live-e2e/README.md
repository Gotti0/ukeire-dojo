# T11 멀티플레이 동풍전 실제 브라우저 종합 검증

실제 `ukeire_dojo.server` (`--live-bot prism --live-device gpu0`), 빌드된 프런트엔드(`web/dist`), Playwright Chromium 다중 브라우저로 2~4인 동풍전 두 경기의 전체 흐름과 응답 시간을 검증한다.

## 재현

사전 조건: `web`에서 `npm run build`를 마치고, [T7 실험](../live-spike/README.md)의 JDK·Epsilon 리뷰어 jar·CUDA libtorch·Prism v760 체크포인트와 Node Playwright가 준비된 Windows 환경에서 실행한다.

```powershell
.\tools\live-e2e\run.ps1
```

## 브라우저 왕복 응답 시간 실측

Windows, RTX 4070 Ti, CUDA BF16 NATIVE(`gpu0`), Playwright Chromium 기준이다. `타패/행동 왕복`은 타패 클릭 후 `POST /action`이 이어지는 AI 판단(최대 2~3석)까지 처리하고 응답을 돌려주기까지의 브라우저 왕복 시간이고, `타패 추천 왕복`은 `AI 타패 추천 보기` 클릭 후 추천 패널이 화면에 표시되기까지의 시간이다.

| 구성 | 항목 | 표본 | p50 | p95 | 최대 |
| --- | --- | ---: | ---: | ---: | ---: |
| 단일 방 (시나리오 A) | 타패/행동 왕복 | 532 | 50.9ms | 161.6ms | 183.1ms |
| 단일 방 (시나리오 A) | 타패 추천 왕복 | 16 | 54.3ms | 63.5ms | 63.5ms |
| 2방 동시 (시나리오 D) | 타패/행동 왕복 | 388 | 83.3ms | 297.6ms | 733.0ms |
| 2방 동시 (시나리오 D) | 타패 추천 왕복 | 24 | 55.8ms | 104.1ms | 108.0ms |

## 제품 응답 시간 목표

단일 GPU `LiveMatchHost` 직렬 처리와 브라우저 왕복 실측을 기준으로 다음 목표를 확정한다.

- **단일 방**: 타패/행동 왕복 p95 **250ms 이내**, 요청형 타패 추천 왕복 p95 **150ms 이내**
- **2방 동시 실행**: 타패/행동 왕복 p95 **500ms 이내**, 요청형 타패 추천 왕복 p95 **200ms 이내**
